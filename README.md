# webbluetooth-drivers

Java APIs for various devices implemented using Vaadin + Web Bluetooth API.

## Modules

### phomemo-driver

A Java API for Phomemo label printers. At this point tested only on Phomemo M110 (Clas Ohlson branded). Supports drawing on Graphics2D, which is then transferred as PNG to browser (and via Web Bluetooth API to the label printer).
